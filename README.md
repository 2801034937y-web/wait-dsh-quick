# Windows 免命令行启动器提示词

> 一份提示词。复制给 AI，让它给你生成一个双击即用的 Windows 启动器。

命令行工具每次都开黑框太麻烦。这份提示词让 AI 生成一个启动器：
双击图标 → 服务在隐藏窗口里跑起来 → 用无地址栏的应用窗口打开界面。

**是一个提示词，不是软件。** 每个人的端口、路径、依赖都不一样，
让 AI 按你的情况生成一份，比改别人的代码省事。

## 这是什么

一份结构化的提示词，里面规定了：

- **必须先问你**：端口、入口路径、有没有一次性 token，猜错一个生成的就是废代码
- **技术边界**：怎么才能真正隐藏窗口、源码编码、图标格式、命令行拼装、路径解析
- **安全边界**：不碰你的软件和数据，不杀不是自己启动的进程
- **验收清单**：交付前逐条自检，做不到要说明，不许静默降级

## 怎么用

1. 打开 [PROMPT.md](PROMPT.md)，复制那个代码块
2. 回答它问的 6 个问题（问题就在提示词里）
3. 把回答拼在提示词后面，一起发给 AI
4. 拿到代码先跑 `-SelfTest`，再双击试

目标不是 DSH 的话，把提示词里"参考：如果目标就是 DSH"那一段删掉。

## 需要你先定三件事

### 1. 图标（唯一的必做手工活）

快捷方式图标**只认 `.ico`**。给 `.png` 不会报错，但图标会变成一张白纸 —— 这是最常见的翻车点。

| 你手上有什么 | 怎么做 |
|---|---|
| `.ico`，内含多个尺寸 | 直接用 |
| `.png` / `.jpg` / `.webp` | 告诉 AI 图片路径让它转；或自己用在线工具转（选"多尺寸 ICO"） |
| 长方形图 | 快捷方式里会被压扁，先裁成正方形，或让 AI 居中裁 |
| 懒得弄 | 不设图标，用系统默认图标，能跑就行 |

尺寸至少要有 16 / 32 / 48 / 256，缺了在大图标视图下会糊。

**图请自己找。** 仓库里的示例图是作者自己的，不要拿去用。

### 2. 端口

选一个不常用的，例如 `3080`、`8123`。被占用了启动器会提示你换一个。

### 3. 运行目录

默认放 `%LOCALAPPDATA%\<工具名>\`。卸载时只删这里，不碰别的东西。

## 生成之后怎么验收

| 步骤 | 看什么 |
|---|---|
| 1. 跑 `-SelfTest` | 什么都不启动，只输出一张依赖诊断表。看依赖是否都找到了 |
| 2. 双击一次 | 没有黑框闪过、没有多余窗口、任务栏没有残留进程 |
| 3. 再双击一次 | 不会重复启动，很快打开窗口 |
| 4. 换台机器试（可选） | 找朋友或换台电脑试，边界问题只有换环境才暴露 |

出问题把自检表贴回给 AI 让它改，不要自己动手改。

## 安全边界

提示词里写死了这几条，生成的代码不应该越过：

- 不安装、不升级、不修改、不删除你的软件
- 不碰你的配置、存档、凭据、会话数据
- 不终止不是它自己启动的进程
- 只写自己的运行目录和桌面快捷方式
- 删除快捷方式前先校验是不是自己建的

拿到代码建议扫一眼，确认没有 `npm install -g`、`Remove-Item` 之类的句子。

## 常见问题

**为什么提示词要 AI 先问一堆问题？**
猜错一个参数生成的代码就是废的。先问清楚比来回返工省事。

**AI 生成的能直接发布吗？**
先用几天。这类工具的坑都在边界情况（端口冲突、依赖搬家、token 失效），短时间测不出来。

**能不能直接给我一个 exe？**
exe 要签名，不然杀软会拦，体积也大。脚本更透明，你能看见它到底做了什么。
